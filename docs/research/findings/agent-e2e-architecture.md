  [Matched comparison](../../dev/b10-continuation/strong-worker-grounding-results.md).

  anchor recovers tentative evidence but never counts as autonomous success.
  [Diagnostic](../../dev/b10-continuation/project-discovery-diagnostic.md).

  synthetic catalog controls. Named fields plus explicit identity guidance pass

  [Synthetic outcomes](../../dev/b10-continuation/synthetic-discovery-results.md).

  entries fail the original 800-unit named format; a separately frozen single-key,
  bounded-label format fits at 532 units. Packing is not task success or coverage.
  [Compact experiment](../../dev/b10-continuation/compact-contract-experiment.md).

  [Real development result](../../dev/b10-continuation/real-discovery-development-results.md).
