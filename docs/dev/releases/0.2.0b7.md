## Scope

General Knowledge Evidence Model (ADR-0029), answering the Day 1 finding that `source authorize`
labelled every one of User #1's MarginNote cards `studied` (26,415 near-identical Profile facts).
Source authority is now a Vault-enforced ceiling; MarginNote cards and GitHub concept items are
classified item by item; `source authorize` re-derives through the classifier and gains
`--grant knowledge.applied` for GitHub; `aptuni source reclassify` is the owner-confirmed migration;
`aptuni knowledge` and a compact `aptuni.profile` expose a derived, cited Knowledge State. Before
release it was rehearsed on a scratch copy of the real Vault (deleted afterwards): `doctor` healthy
under the new invariant (106,204 records), reclassify downgraded 3,737 isolated cards in 3.6 s,
22,678 studied facts remained, and a second run changed nothing. Top-Down Learning stays 0.2.1.

Compatibility (fail closed): 0.2.0b6 and older cannot open a Vault holding a `knowledge.applied`
grant, and refuse to sync a MarginNote or GitHub source last synced by 0.2.0b7. The tagged CHANGELOG
words this less precisely; the corrected wording is on `main` after the tag.
