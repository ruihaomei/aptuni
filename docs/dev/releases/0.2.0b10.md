# Aptuni 0.2.0b10 (Beta) release record

**Released:** 2026-10-09

**Release commit:** `be77274` (tag `v0.2.0b10`, annotated)

**Authorization:** on 2026-10-09 the maintainer accepted ADR-0032 and asked in chat to tag and
publish 0.2.0b10 ("接受 ADR-0032，打 tag 发布 0.2.0b10"). The decision rests on Review 114 and the
production-path confirmation in `docs/dev/b10-continuation/candidate-inventory-confirmation.md`.

This record is immutable release evidence. Beta defects ship in a new pre-release.

## Scope

Grounded selection via the candidate inventory (ADR-0032). Host-named concept queries (ADR-0030)
and credentials kept out of Evidence and Context (ADR-0031) accumulated since 0.2.0b9. No Vault
migration.

## Release history

The first `v0.2.0b10` tag (`5b7594a`) failed the release gate before publishing. `tests/dev` ran
under the bare system Python, which cannot import the research-harness tests, and two runner tests
needed a local Codex CLI. Fixes `960b761` (run the dev tests through uv) and `be77274` (hermetic host
version probe) made CI pass. The unpublished tag was then moved to `be77274`. Nothing had been
published under the first tag.
