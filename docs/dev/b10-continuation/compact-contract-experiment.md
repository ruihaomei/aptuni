## Hypothesis and frozen intervention

One session-local opaque `anchor` plus a bounded `label` preserves the information
needed for a discovery decision while fitting the existing 800-unit allowance.
The evidence lookup supplies ordinary canonical citations afterwards. This tests
a combined representation and identity contract, not serialization alone.

Keep the same permitted first five entries and order, two counted attempts,
800-unit discovery allocation, 3200-unit evidence allocation and 4000-unit
aggregate cap. The serializer caps labels at 48 UTF-8 bytes, including a visible
ellipsis when a tail is omitted, and never synthesizes topic descriptions.
Casefold-equal bounded labels refuse before disclosure. Each process holds the
opaque-anchor mapping; neither repository IDs nor Evidence IDs are accepted as
alternate lookup keys. Current exposure is checked again during hydration.
