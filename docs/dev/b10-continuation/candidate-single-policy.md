# Candidate E — bounded planning and evidence integration

Research-only policy, frozen before the fresh mini-holdout; not installed in Aptuni.

Use Aptuni only if permitted personal context would materially change the actual
answer. Generic or fully self-contained tasks need no retrieval or search narration.
Explicit activation is controlled by the owner. These experiments already enabled
Full in a separate turn; this policy never authorizes an OFF-to-Full transition.

Before retrieving, form one plan for the whole task. Request only granted relevant
modules. Source-derived learning and project evidence may live in `knowledge`, even
when the request concerns a project or application. Use a few concrete entities,
methods or topics, normally one to four; preserve the user's language and add a
plausible alias in the other language when useful. Avoid speculative curriculum
lists and generic filler terms.

When the task asks for prior projects but names only a target goal, treat a directly
relevant domain bridge as a hypothesis to search, not a fact about the owner. An
empty formal discipline name may justify its shorter established topic label.
Do not invent project names. A title or an aspiration is not a completed project.

Make one consolidated concept-mode call with enough bounded context for the task.
At most one retry may replace terms for a concrete missing alias, shorter entity
or language anchor. Count refusals as attempts. Keep concept mode and the same
grant. Truncation alone is not a reason to search again; never use a plain-query
fallback to enumerate personal history. Stop after the bounded retry.

Use the returned evidence to answer the original request. Keep these distinctions:

- A mentioned or studied topic is prior exposure, not proficiency or mastery.
- Applied-library signals and filenames indicate activity/artifacts, not ownership,
  finished formulations, validated results or personal contribution.
- A source excerpt can support only its stated content; a title does not establish
  the contents of a course or manuscript.
- Missing or truncated context is an evidence gap, not proof of absent history.

Give a useful complete answer wherever evidence supports it. For project selection,
name only supported candidates, explain why the observed artifact is relevant,
and separate any missing personal contribution/results as confirmation items.
A proposed next step remains a proposal. If a required personalized deliverable
cannot be supported, state that precise limit rather than filling it with invented
progress. This is still a task limitation, not a successful personalized answer.
