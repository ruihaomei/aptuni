2026-10-05. Research-only, invented records. This does not reuse the prior s01 task or
claim live-Vault acceptance. No production behavior, authorization or grants change.

## Fixed hypothesis and arms

The observed prior failure is insufficient support for a required two-candidate
selection in returned packets. Corpus recall is unknown. The fixed hypothesis is
that a bounded source-group candidate roster before ranking improves the complete
selection task. A logical roster derived from existing record grouping metadata
is the sole automatic-path intervention.

- **Baseline:** strong single Agent with ordinary context search.
- **Auto:** same Agent and source scope; fixed coverage roster then selected-ID
  Evidence fetch for selection tasks.
- **Directed:** same roster/search/fetch surface and source scope; explicit
  retrieval-planning delegation lets the Agent choose queries and sequence.

All arms use Codex CLI 0.155.1, `gpt-6-astra` at `xhigh`, one fresh ephemeral
session per task, the same invented 13-record fixture, explicit empty Full
session setup, knowledge-only read scope, no hidden-record exposure, at most
three counted retrievals and 4000 response units. No memory writes, web,
filesystem or unrelated MCP tools are offered in the task. The mock is not an
installed Aptuni interface or a proof of OS confinement.

## Run and grade

Run order is s01 baseline → auto → directed, then s02 directed → auto →
baseline. Run each once. Do not inspect quality, retune, replace a task, change
source records or rerun before all six attempts finish. An operational failure
stays in the denominator as incomplete and may not be replaced silently.

After all six complete, grade the original-task requirements first using the
frozen rubric. Then inspect returned canonical IDs, selected IDs, citations and
claim support. Finally unmask resources: retrieval calls, refused/retry calls,
response units, task input/output tokens, and setup/task/journey latency.
Selected-candidate correctness requires both gold groups without a substitute;
candidate recall is gold groups in returned Evidence before the answer, divided
by two. Labels alone do not count as returned Evidence. A complete answer also
needs useful comparison/pitch and bounded claims. Report each arm's denominator,
not just successes. No statistical generalization from two invented tasks.

The outcome rule is predeclared: prefer the lightest single-Agent automatic path
on an E2E tie. An optional directed interface needs at least one additional
complete task with no regression and a small primitive set before product work
is justified. This synthetic result alone cannot release b10 or authorize a
production privacy/interface change.
