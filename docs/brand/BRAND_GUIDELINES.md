# Aptuni Brand Guidelines

> **A personal context layer that grows more attuned to you over time.**

**Aptuni = Adaptive + Attuned**

Aptuni 是一个 local-first、modular、agent-native 的 Personal Context & Memory Framework。\
它的核心不是“尽可能多地记住用户”，而是：

> **在正确的任务、正确的时间，以尽可能少的 context，向 Agent 提供最 relevant、accurate、fresh、verifiable 且 user-permitted 的个人信息。**

Aptuni 的品牌应始终围绕一个核心体验展开：

> **The more you use it, the more attuned it becomes to you.**\
> **越用，越懂你。**

---

# 1. Brand Essence / 品牌本质

## 1.1 Name

**Aptuni**

构词来源：

- **Adaptive** — 能根据用户不断调整
- **Attuned** — 与用户逐渐调谐、形成默契

品牌名表达的不是“存储更多信息”，而是：

> **AI Agent gradually gets attuned to the user.**

Aptuni 不只是 Memory，也不只是 Knowledge Base。\
它更准确的定位是：

> **A personal context layer between you and your AI agents.**

---

## 1.2 Brand Thesis

### Primary

> **A personal context layer that grows more attuned to you over time.**

### Short brand line

> **Context, attuned to you.**

### Experience promise

> **The more you use it, the better it understands what matters.**

### Product explanation

> **Aptuni gives AI agents the right personal context — without giving them everything about you.**

中文版可根据场景使用：

> **一个会随着使用逐渐更懂你的个人上下文层。**

> **把恰到好处的“你”，提供给你的 Agent。**

> **越用，越懂你。**

# 2. Product Philosophy / 产品哲学

Aptuni 的品牌必须反映以下产品原则。

## 2.1 Attunement over accumulation

不是：

> Store everything about the user.

而是：

> Understand what matters, when it matters.

Memory 越多不等于 Personalization 越好。

Aptuni 追求：

$$
\text{Useful Personalization}
=
\frac{
\text{Relevant}
\times
\text{Accurate}
\times
\text{Fresh}
\times
\text{Permitted}
}{
\text{Tokens}+\text{Noise}
}
$$

---

## 2.2 Profile ≠ Memory ≠ Context

```text
Profile
   +
Memory
   +
Evidence
   +
Permission
   ↓
Context
   ↓
Agent
```

品牌传播中应尽量突出 **Context**，而不是把 Aptuni 简化为一个 memory database。

---

## 2.3 Progressive understanding

Aptuni 不应给人“第一次安装就监视你所有数据”的感觉。

正确感受是：

```text
陌生
 ↓
观察
 ↓
理解
 ↓
调谐
 ↓
默契
```

系统随着使用逐渐成长。

---

## 2.4 User ownership

Aptuni 应传递：

- local-first
- transparent
- modular
- permission-aware
- user-controlled
- portable

用户拥有：

```text
Profile
Memory
Evidence
Sources
History
Provider choices
```

Aptuni 只负责：

> **turning those assets into excellent personal context.**

# 3. Brand Personality / 品牌人格

Aptuni 的品牌人格可以概括为：

> **Warm Technical + Calm Intelligence + Friendly Infrastructure**

应体现：

| Trait | 含义 |
|---|---|
| **Attuned** | 越来越理解用户 |
| **Adaptive** | 会随着新证据调整 |
| **Personal** | 像私人 assistant，而不是企业中台 |
| **Trustworthy** | 尊重隐私、边界与用户控制 |
| **Lightweight** | 心理上和技术上都不笨重 |
| **Calm** | 不夸张、不“AI 魔法化” |
| **Technical** | 足够让开发者信任 |
| **Friendly** | 普通用户也愿意接近 |
| **Modular** | 可插拔、可组合、可演进 |
| **Alive** | Profile 会随时间变化，而不是静态档案 |

# 4. Tone of Voice / 品牌语气

## Do

- 清晰
- 克制
- 有温度
- 技术准确
- 解释复杂概念时用生活语言
- 强调“选择体验”，而不是让新手选择技术名词
- 强调用户控制权
- 用 “learn”, “attune”, “adapt”, “context” 等词

## Avoid

- “We know everything about you.”
- “Your AI clone.”
- “Permanent memory of everything.”
- 过度拟人化或 creepy 的描述
- 过度承诺 “never forgets”
- 把用户能力机械化打分
- 企业咨询式空话
- 过多 AI buzzwords

# 5. Core Visual Metaphor / 核心视觉隐喻

## The Tuning Companion

Aptuni 最重要的视觉母题是：

> **一个波代表 User，一个波代表 Agent。\
> 两种不同的频率逐渐调谐、对齐、形成共振，最终构成一个 friendly personal companion。**

视觉叙事：

```text
User Wave        Agent Wave
    ∿                ≋
     \              /
      \            /
       →  tune  ←
          ↓
      alignment
          ↓
      companion
```

它同时表达：

- User 与 Agent 起初并不完全对齐
- Aptuni 持续积累证据与上下文
- 二者逐渐形成共振
- 最终产生“越用越懂你”的体验

# 6. Current Logo Concept / 当前图标设计

当前 Aptuni logo 已形成以下核心结构：

## 6.1 Two interlocking waves

外部由两条柔和、连续、彼此呼应的波形组成。

- 深蓝色一侧：可解释为 **User / stable context / identity**
- 青绿色一侧：可解释为 **Agent / adaptation / evolving understanding**

不要求在所有传播场景中强行解释左右归属；重点是“两种信号逐渐对齐”。

---

## 6.2 Companion face

两条波形围合出的负空间形成一个简洁的小型 companion / personal assistant。

当前形象包含：

- 两个极简圆点眼睛
- 一个柔和微笑
- 无复杂机械细节
- 无传统“机器人天线/电路”元素

它应让人觉得：

> friendly, attentive, calm, intelligent

而不是：

> childish, robotic, surveillant

---

## 6.3 Negative space

中心的大面积白色负空间很重要。

它象征：

- breathing room
- lightweight context
- signal over noise
- user ownership
- only the necessary context

不要为了“更丰富”而把中心填满节点、电路或复杂图案。

---

## 6.4 Continuous loop

波形整体接近一个连续循环。

可以隐喻：

```text
interaction
→ memory
→ profile
→ context
→ better interaction
→ ...
```

这是 Aptuni 的 **personalization compounding loop**。

# 18. Brand Experience Principles / 品牌体验原则

视觉和交互必须共同体现 Aptuni。

## Invisible complexity

> **无感和心理上的轻量，是核心 UX 原则。**

用户不需要理解：

```text
Mem0
Graphiti
embedding
vector DB
```

就可以使用 Aptuni。

---

## Experience before technology

不要问：

> Which memory backend do you want?

而问：

> How would you like your Agent to remember you?

---

## Progressive complexity

```text
Lite
↓
Smart
↓
Advanced
```

复杂度随着价值出现。

---

## Transparent personalization

当 Aptuni 学到新的稳定 preference 时：

- 可以自动使用
- 保留 provenance
- 允许事后 review
- 允许 edit / reject / forget

让用户感受到：

> “它越来越懂我。”

而不是：

> “它在偷偷记录我。”

Design a minimalist, memorable vector logo for an open-source AI project named **Aptuni**.
