# Aptuni brand

- **Guidelines:** [`BRAND_GUIDELINES.md`](BRAND_GUIDELINES.md). Read them before changing the
  README, docs, website, Obsidian plugin or promotional assets.
- **Name:** Aptuni (= Adaptive + Attuned). Python distribution and import name: `aptuni`.
- **Tagline:** "Context, attuned to you." Position Aptuni as a *personal context layer*, never as a
  memory database.

## Assets (`assets/brand/logo/`)

| File | Use |
|---|---|
| `aptuni-icon.svg`, `aptuni-icon.png` | Icon on a transparent background (avatar, favicon source, plugin icon) |
| `aptuni-icon-on-white.svg`, `aptuni-icon-on-white.png` | Icon on white |
| `aptuni-primary.png` | Primary lockup (icon + wordmark), README hero reference |

Per the guidelines, these are still pending: a vector master re-export, monochrome variants, a
horizontal lockup, a favicon, and a social preview. Any major brand change needs maintainer review.
