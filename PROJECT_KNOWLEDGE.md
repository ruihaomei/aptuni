# Project knowledge (Research Memory router)

Aptuni keeps its development research memory thin and repo-native. There is no database and no
status command.

- Research index: [`docs/research/INDEX.md`](docs/research/INDEX.md) (upstream notes, rejected
  approaches, pitfalls)
- Current state and next action: [`docs/dev/STATE.md`](docs/dev/STATE.md),
  [`docs/dev/HANDOFF.md`](docs/dev/HANDOFF.md)
- Settled decisions: [`docs/dev/DECISIONS/`](docs/dev/DECISIONS/README.md)
- Known issues and backlog: [`docs/dev/KNOWN_ISSUES.md`](docs/dev/KNOWN_ISSUES.md),
  [`docs/dev/BACKLOG.md`](docs/dev/BACKLOG.md)

Update the research files when you learn something reusable. If a richer research backend ever
becomes worth it, add it behind an adapter; these files stay canonical.
