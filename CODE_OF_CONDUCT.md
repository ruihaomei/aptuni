# Code of Conduct

Aptuni adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies in every project space: issues, pull requests, discussions and
any community channel, and when someone represents the project in public.

In short: be welcoming, be kind, assume good intent, and give and accept constructive feedback
gracefully. Harassment, personal attacks, and publishing anyone's private information are not
acceptable. Given what Aptuni is for, that last point includes other people's personal context,
Vault content and data samples.

## Reporting

Report unacceptable behavior to the maintainer privately, through GitHub private vulnerability
reporting on this repository with "Code of Conduct" in the title, or through a direct message to a
maintainer listed in [`.github/CODEOWNERS`](.github/CODEOWNERS). Reports are handled promptly and
confidentially.

## Enforcement

The maintainer enforces this code following the Contributor Covenant 2.1 enforcement guidelines:
correction, warning, temporary ban, and permanent ban, depending on the impact of the behavior.
